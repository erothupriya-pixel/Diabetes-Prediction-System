# Diabetes Prediction System

## Overview
This project predicts whether a patient has diabetes using Machine Learning.

## Features
- Data Cleaning
- Data Analysis
- Data Visualization
- Logistic Regression Model
- Accuracy Evaluation
- Patient Prediction

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
Diabetes Dataset from Kaggle

## Project Workflow
1. Load Dataset
2. Clean Data
3. Analyze Data
4. Visualize Data
5. Train Machine Learning Model
6. Predict Diabetes
